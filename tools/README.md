# Երգերի տվյալները (մեկ աղբյուր)

Երգերը նկարագրվում են **միայն** `artist-pages-data.json`-ում։ Գլխավոր էջը (`index.html`)
կարդում է դրանք ինքնաբերաբար ստեղծվող `songs-data.js` ֆայլից։

## Նոր երգ ավելացնելու համար

1. mp3 ֆայլը վերբեռնիր R2-ում՝ `audio/<արտիստ>/featured/<երգի id>.mp3`։
2. `artist-pages-data.json`-ում, արտիստի `tracks` ցանկի վերջում ավելացրու.

```json
{
  "id": "երգի id (ֆայլի անունը առանց .mp3)",
  "label": "Երգի անունը (հայերեն)",
  "src": "https://pub-2d663d6d59994b7fa7390c9851966548.r2.dev/audio/<արտիստ>/featured/<երգի%20id>.mp3",
  "explanation": { "en": "English title", "ru": "Русское название" },
  "added": "2026-10-04"
}
```

   `added` ամսաթիվը ըստ ցանկության է. 30 օր երգի կողքին երևում է **NEW**։
3. Commit արա `main`-ում։ GitHub-ը ինքը կգործարկի `Build songs data` workflow-ը,
   կստեղծի նոր `songs-data.js`-ը և կհրապարակի կայքը (1–2 րոպե)։

Ձեռքով գործարկելու համար (օրինակ՝ փորձարկման ժամանակ).

```
python tools/build_songs_data.py
```

## Կանոններ

- `id`-ն պետք է լինի եզակի բոլոր արտիստների միջև։
- `label`-ի լեզուն համարվում է երգի «սեփական» լեզուն. `explanation`-ում գրվում են **մյուս** լեզուները։
- `songs-data.js`-ը ձեռքով մի փոխիր, այն վերագրվում է ամեն անգամ։
