Երգ ավելացնել կամ փոխել առանց ծրագրավորման։ Միայն քեզ համար։

1. Մուտք (GitHub բանալի)

Բանալին պահվում է միայն այս բրաուզերում և ուղարկվում է միայն GitHub-ին։
Ինչպես ստանալ բանալին (մեկ անգամ)
  1. Բացիր GitHub → New fine-grained token։
  2. Repository access → Only select repositories → ընտրիր Imastun_New_Site։
  3. Permissions → Repository permissions → Contents → Read and write։
  4. Սեղմիր Generate token և պատճենիր (սկսվում է github_pat_-ով), փակցրու վերևում։
